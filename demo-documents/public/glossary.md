# Glossaire du laboratoire

- RBAC : attribution de droits par rôle.
- ACL : règle définissant qui peut accéder à une ressource.
- RAG : récupération de passages avant l’appel au modèle.
- MCP : protocole futur permettant à un agent d’utiliser un outil encadré.
